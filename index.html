О сайте

Это простой одностраничный сайт, созданный на чистом HTML и CSS. Его можно опубликовать на GitHub Pages буквально за пару минут.

Что здесь есть

Адаптивная вёрстка, градиентная шапка, карточки с тенями и кнопка. Всё уместилось в один файл без внешних библиотек.

Перейти на GitHub

Как опубликовать

Загрузите этот файл как index.html в репозиторий, включите Pages в настройках — и сайт уже в интернете.
